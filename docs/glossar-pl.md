# Słownik DE→PL (wiążący dla tłumaczenia)

Ten słownik ustala polską terminologię **przed** tłumaczeniem, aby ~1300 etykiet i ~40 tys. słów treści pozostało spójne. Każda osoba tłumacząca (człowiek lub SI) trzyma się prawej kolumny dla wymienionych terminów. Źródłem pozostaje niemiecki (`data/labels/de.json` + węzły treści `"de"`).

Konwencje: standardowa polszczyzna, forma bezpośrednia (zwracanie się przez „ty", ciepło i pouczająco, bez sztywności). Symbole zastępcze `{n}`/`{a}`/`{titel}` pozostają bez zmian. Marki / nazwy własne **nie** są tłumaczone. Polskie cudzysłowy „ … " zamiast „ … ".
