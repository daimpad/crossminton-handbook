    How the simulator calculates

    It assumes 40 seconds per point, with a range of 35 to 45. On average the losing side scores 70% of the winner's points, so a set to 16 runs to about 27 points.

    The stronger side wins a set 70% of the time. With “Sets to win” at 2, the average number of sets per match is 2.4.

    Between two matches on the same court, and between two matches of the same person, the gap is always at least the changeover time. Each court that becomes free gets the match that can start there earliest; in the knockout format, a match can only start once both of its feeder matches have finished.

    If the number of entries is not a power of two, the top seeds get a bye in round 1.
