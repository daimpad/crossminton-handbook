    Comment le simulateur calcule

    Le simulateur compte 40 secondes par point, avec une fourchette de 35 à 45. Le camp perdant marque en moyenne 70 % des points du gagnant ; un set en 16 points compte donc environ 27 points joués.

    Le camp le plus fort remporte un set avec une probabilité de 70 %. Sets gagnants : 2 ; nombre moyen de sets par match : 2,4.

    Entre deux matchs sur un même terrain et entre deux matchs d'une même personne s'écoule au moins le temps de battement. Chaque terrain qui se libère reçoit le match qui peut y commencer le plus tôt ; en élimination directe, seulement une fois terminés les deux matchs dont il découle.

    Si le nombre d'inscriptions n'est pas une puissance de deux, les premières têtes de série sont exemptées du tour 1.
